# دستیار تحقیق

پروژه آموزشی برای پیاده سازی الگوهای اصلی Agentic AI با LangGraph که با جستجو در منابع مختلف به سوال های تحقیقاتی جواب میدهد

- **برنامه ریزی (Planning):** قبل از جستجو یک برنامه تحقیق چند مرحله ای برای سوال میسازد
- **استفاده از ابزار (Tool Use):** با یک Agent در وب و ویکی پدیا و مقالات arXiv جستجو میکند و منبع هر اطلاعات را میگوید
- **بازتاب (Reflection):** پیش نویس جواب خودش را نقد میکند و یک گزارش از نقاط قوت و ضعف همراه با نسخه اصلاح شده جواب میدهد
- **حافظه (Memory):** با Checkpointer در LangGraph گفتگو را به خاطر میسپارد و سوال های ادامه دار را میفهمد
- **گراف LangGraph:** سه نود planner و researcher و reviewer پشت سر هم اجرا میشوند
- **مقاوم سازی:** اگر ابزاری خطا بدهد یا مدل بیش از حد جستجو کند برنامه متوقف نمیشود و با اطلاعاتی که دارد جواب میدهد
- **معماری:** رابط کاربری Streamlit و بک اند FastAPI جدا از هم هستند و از طریق API با هم ارتباط دارند
