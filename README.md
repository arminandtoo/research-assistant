# دستیار تحقیق

یک دستیار هوش مصنوعی که با جستجو در منابع مختلف به سوال های تحقیقاتی شما جواب میدهد

- اول برای سوال شما یک برنامه تحقیق میچیند
- بعد در وب و ویکی پدیا و مقالات arXiv جستجو میکند و یک پاسخ اولیه مینویسد
- سپس پاسخ خودش را نقد میکند و نسخه بهتری از آن ارائه میدهد
- گفتگو را به خاطر میسپارد و سوال های بعدی را در ادامه همان گفتگو میفهمد

ساخته شده با LangGraph و FastAPI و Streamlit
